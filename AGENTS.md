# webgate

Homelab web access service: search / fetch and the adapters behind them. Callers (such as `ai-news`) talk to this process; they do not talk CDP.

## Agent skills

### Issue tracker

GitHub Issues on `sidkang/webgate` via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
